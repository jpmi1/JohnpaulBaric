# JohnPaul Baric — Personal Site (v4)

## Quick start (GitHub Pages)
1. Copy everything in this folder to your repo root.
2. Ensure GitHub Pages is enabled (Settings → Pages → Deploy from `main` / root).
3. Replace images in `/images/` as needed.

## Key files
- `index.html` — structure/sections
- `stylesheets/landing.css` — dark theme + layout
- `javascripts/site-data.js` — edit content here
- `javascripts/landing.js` — animations + rendering
